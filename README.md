# Entware Dashboard для Keenetic

Универсальный скрипт-дашборд для удобного управления **Entware** на роутерах **Keenetic**.

---
# 🚀 Установка
  
Скопируйте и вставьте команду в среде Entware, затем выберите пункт «Установить» и после завершения переподключитесь к терминалу:
```
opkg install curl && curl -L -s "https://raw.githubusercontent.com/LostGit77/ENTWARE-Dashboard/refs/heads/main/install_dashboard.sh" > /tmp/banner.sh && sh /tmp/banner.sh
```
# 🧹 Удаление
  
Скопируйте и вставьте команду в среде Entware, затем выберите пункт «Удалить» и после завершения переподключитесь к терминалу:
```
curl -L -s "https://raw.githubusercontent.com/LostGit77/ENTWARE-Dashboard/refs/heads/main/install_dashboard.sh" > /tmp/banner.sh && sh /tmp/banner.sh
```

## 🛠 Возможности

### 📊 Мониторинг системы
При запуске отображается наглядная консольная панель со статусом системы:

- Загрузка CPU  
- Температура устройства  
- Использование оперативной памяти  
- Свободное место на диске  
- Статус сервисов  
- Доступные обновления  

---

### 📦 Установка сервисов
Установка популярных панелей и утилит в один клик:

- **neofit** — панель управления  
- **x-ui** — 3x-ui панель для роутера  
- **hrneo / hrweb** — HydraRoute  
- **magitrickle** — управление трафиком  

---

### ⚙️ Обслуживание и управление

Скрипт создает удобные команды (симлинки), чтобы не вводить полный путь:

- `install` — установка сервисов  
- `update` — обновление пакетов Entware и самого скрипта  
- `remove` — полное удаление сервисов с конфигурациями  
- `manager` — менеджер дисков и резервных копий  
- `banner` — отображение статуса системы  
- `link` — быстрый доступ к официальным источникам  

---

## 🎯 Назначение

Скрипт создан для упрощения работы с Entware:

- Не нужно искать и читать разные инструкции  
- Все управление собрано в одном месте  
- Удобное и понятное меню  
- Быстрая установка и обслуживание сервисов
